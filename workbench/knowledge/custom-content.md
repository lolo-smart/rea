# 我们的工作台与本地积累

## 已进入此独立 fork 的内容

| 文件 | 用途 | 关键行为 |
| --- | --- | --- |
| `workbench/Install-Workbench.ps1` | 安装与仓库声明版本一致的官方运行包 | 默认跳过 npm 生命周期脚本；不会安装或升级 Node、Java、Ghidra 等外部依赖 |
| `workbench/rea.ps1` | 各工程共用的 CLI 入口 | 从忽略的 providers 配置读取允许的显式键；临时应用后在 finally 恢复环境 |
| `workbench/Verify-Workbench.ps1` | 生产 MCP 自检与可选 IL2CPP 检查 | 元数据验证写独立时间戳目录；可选 BinaryPath，避免覆盖旧证据 |
| `workbench/providers.example.json` | 脱敏配置样板 | 真实路径和配置留在 `.local/providers.json` |
| `workbench/upstream.json` | 最初 6.8.0 整合来源 | 记录稳定包/tag 身份；其中 source_sync 是当时的整合历史，不是当前 main 的实时状态 |
| `workbench/README.zh-CN.txt` | Windows 使用与边界 | 区分官方分析器、工作台、外部引擎与未验证范围 |
| `workbench/knowledge/` | 本次新增的跨工程知识库 | 能力、案例、纠正、复用步骤和结构化登记表 |

这些是本 fork 的整合与知识贡献。并没有另写一套 IL2CPP、Ghidra 或 Android 分析引擎；相应能力及许可证仍按上游说明。

## 留在本机的积累

- 发行包身份、原件、逐文件清单与完整 Evidence，以及只读派生产物。
- Unity 资源、预制体、类型、配置表、视频帧与运行表现的索引和历史核查脚本。
- 按问题产生的依赖恢复、GUID 映射、Shader、运行时与离线启动修复记录。
- 工作台运行包、机器 providers、安装校验、能力自检、升级分析与历史备份。
- 各工程自己的 `.learnings`、测试日志、图片、录像、存档和未公开实现。

上面内容不能整目录复制到 REA 或游戏 GitHub。公共知识库只提炼可复用的方法和经过核对的范围；私有来源索引仍在本机。

## 已纠正的整合问题

1. `Get-Command node` 可能返回多个可执行文件；工作台选取第一个应用命令，避免数组被当路径使用。
2. 旧 CLI 启动器可能仍指向旧版；本机保留兼容转发，但新工程优先调用独立工作台。
3. 运行包、已加载 MCP、技能和源代码分支可能属于不同版本；需要分别核对身份，不能只看安装成功信息。
4. 历史分析器和大证据不等于垃圾。清理曾采用文件集合/哈希确认后删除重复项，保留不能证明重复的原件和历史证据。

本库不发布原游戏的还原代码、资源、APK、EXE、私有服务地址、凭据或完整抓包，也不把游戏工程里的重建代码归为 REA 通用能力。
