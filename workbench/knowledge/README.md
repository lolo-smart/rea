# 本机 REA 与跨工程经验库

整理日期：2026-11-08（Asia/Shanghai）。维护仓库：`lolo-smart/rea`；官方上游：[`morluto/rea`](https://github.com/morluto/rea)。

这里汇总本机可调用能力、此 fork 的工作台和其他工程实践产生的方法。官方分析能力归上游；我们的新增内容是 Windows 调用整合、验证入口、经验归纳和交接规范。游戏源码、素材、样本及完整 Evidence 不在本目录发布。

本次新执行的是 CLI 版本检查、能力探测、生产 stdio MCP 自检以及资料核对。MCP 自检为 229/229 工具、6/6 提示词，当前聊天也暴露 229 项 REA 工具；CLI 目录声明 175 个命令。目录数量表示接口规模，不能当成逐项真实样本验收。

案例主要依据此前落盘的报告、清单、经验记录及相关聊天。它们明确标为历史执行；本次没有重跑四款游戏，也没有重新验收游戏画面、联机、声音或通关。

本库不是自动采集器。其他聊天的经验不会自动进入 GitHub；每次使用后需要按模板整理，核对来源、去除私密信息，再提交。原始资料到公开总结的映射保存在本机忽略目录，便于复核。
