# 跨工程经验记录模板

模板本身不是执行证明。公开草稿填写通用结论，本地来源索引单独保存原始记录位置。

```text
案例 ID / 经验 ID：
记录日期与来源执行日期：
任务问题：
目标格式 / 版本 / 架构：
REA 运行包与已加载 MCP 版本：
外部工具、provider 与目标支持：

观察到的症状：
REA 直接观察：
辅助工具结果：
派生投影或重建实现及其版本：
原判断为何不足 / 用户纠正：
根因与实际修正：

实际执行的验证与条件：
输入是否真实、是否经过生产入口：
图像/行为/数值/退出/存档分别覆盖什么：
失败、部分结果、清理状态：
没有执行或无法证实的项目：

可复用规则与适用边界：
证据种类：历史执行复核 / 本次执行 / 静态分析 / 推断 / 待验证
公开结论：
本地来源索引 ID：
后续验证与失效条件：
```

同一条经验允许由部分失败产生，但不能填写未执行的通过结果。公开记录不粘贴完整聊天、私有源码或原始 Evidence。
